# Screen13-Notebook

Sổ từ: lưới thẻ từ, mỗi thẻ viền 4px màu `mastery-1..5` + 5 chấm + tên mức; bộ lọc chủ đề dạng chip radio.

- Sắp xếp mức thấp trước để ưu tiên ôn.
- Lưới tự xuống dòng `minmax(196px, 1fr)` và cuộn bên trong.
- Mức 1–2 viền nhạt nên luôn có chấm + chữ đi kèm.

4 trạng thái dữ liệu (Bình thường · Đang tải · Trống · Lỗi) và 3 cỡ màn (1440×900 · 1366×768 · 1920×1080, nội dung tối đa 1440px căn giữa) xem ngay trên thẻ xem trước.
