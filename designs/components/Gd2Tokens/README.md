# Gd2Tokens

Token bổ sung giai đoạn 2.

- Tất cả có trong `tokens.json` và trang token của hệ thống.
- Đọc to & ghép âm: `read-highlight`, `phon-slot`, `duration-read-word`, `size-phon-tile`.
- Ghi âm: `rec`, `rec-soft`, `rec-track`, `size-mic`, `duration-rec-max` (tím, không dùng đỏ).
- Bong bóng: `bubble-1…5`, `bubble-shine`, `game-sky`, `game-sky-2`, `size-bubble`, `duration-bubble-rise`.
- Đập chuột: `mole-ground`, `mole-ground-shade`, `mole-hole`, `mole-hole-rim`, `mole-fur`, `mole-belly`, `mole-tongue`, `size-mole-hole`, `duration-mole-up`.
- Đua xe: `race-grass`, `race-track`, `race-track-edge`, `race-ghost`, `race-ghost-line`, `race-finish-a`, `race-finish-b`, `size-race-lane`.
- Trùm: `boss-energy`, `boss-energy-shade`, `boss-energy-track`, `boss-fur`, `boss-face`, `size-boss`. Cổng: `gate-stone`, `gate-stone-shade`, `gate-glow`, `gate-dark`. Bài thi: `size-test-dot`.
- Rồng lớn lên: `dragon-egg`, `dragon-egg-spot`, `dragon-leaf` (= `level-2`), `dragon-scarf-4` (= `level-4`), `dragon-scarf-5` (= `level-5`).
- Thời lượng là tốc độ chuyển động, không phải đồng hồ đếm ngược.
