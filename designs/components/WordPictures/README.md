# WordPictures

Hình minh hoạ cho từ vựng tiếng Anh: viền `dragon-line` 3px, khối màu phẳng, khung 120×120, không chữ trong hình.

- Gọi `Bong.pic(word, size)`; dữ liệu từ (`Bong.words`) gồm nghĩa, phiên âm, câu ví dụ, chủ đề.
- Màu bên trong hình minh hoạ là màu vẽ, không phải token giao diện.
- Từ hiện kèm hình luôn có nút loa bên trái.
