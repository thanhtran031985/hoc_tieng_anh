# Thcs10-LessonEnd

Kết thúc bài THCS: % câu đúng, XP nhận được, huy hiệu mới (nếu có), từ vựng vừa học (có loa), điểm ngữ pháp, câu cần xem lại kèm lý do; nút Về lộ trình và Bài tiếp theo (Enter).

- XP luôn dương; câu sai tự vào Ôn tập.
- Lỗi lưu kết quả: XP giữ trên máy, cho Thử lại.

Thẻ xem trước có 4 trạng thái dữ liệu (Bình thường · Đang tải · Trống · Lỗi), 3 cỡ màn (1440×900 · 1366×768 · 1920×1080) và công tắc Sáng / Tối.
