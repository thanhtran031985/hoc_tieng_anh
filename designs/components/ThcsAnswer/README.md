# ThcsAnswer

Ô đáp án một dòng cho câu trắc nghiệm: ô chữ cái A–D (kèm số 1–4 nhỏ ở góc) + nội dung tiếng Anh `thcs-en` (20px) + biểu tượng kết quả.

- Chọn bằng chuột, phím `1`–`4` hoặc `A`–`D`; `Enter` kiểm tra. Ô là `role="radio"` với `aria-keyshortcuts="1 A"`.
- Đang chọn: viền 2px `brand`, nền `brand-soft`. Đúng: viền `success-shade`, nền `success-soft`, ✓. Chưa đúng: viền `retry-shade`, nền `retry-soft`, ↻, lắc nhẹ — **kèm giải thích ngắn vì sao sai** trong dải phản hồi, rồi cho chọn lại.
- Mờ (`is-dim`): khi bấm Gợi ý (`H`) loại bớt một đáp án sai.
- Focus: `thcs-focus-ring`.
