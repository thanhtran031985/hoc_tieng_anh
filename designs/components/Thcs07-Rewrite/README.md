# Thcs07-Rewrite

Viết lại câu không đổi nghĩa: câu gốc (có loa), phần đầu câu mới cố định, ô gõ phần còn lại.

- Chấm theo nhiều đáp án đúng (learned / learnt / been learning…), bỏ qua hoa thường và dấu câu.
- Chưa đúng: chẩn đoán lỗi cụ thể (since/for, ago, dạng V3, thiếu before) rồi sửa ngay trong ô.
- H mở từ gợi ý dạng chip, bấm để chèn; Enter trong ô là Kiểm tra.

Thẻ xem trước có 4 trạng thái dữ liệu (Bình thường · Đang tải · Trống · Lỗi), 3 cỡ màn (1440×900 · 1366×768 · 1920×1080) và công tắc Sáng / Tối.
