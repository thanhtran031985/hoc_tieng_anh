# Screen03-CreateProfile

Luồng tạo hồ sơ 3 bước với thanh bước ở đầu: (1) tên và lớp, (2) chọn bạn rồng, (3) kiểm tra loa và micro.

- Chân màn: Quay lại (`secondary`) bên trái, Tiếp tục (`primary`, Enter) bên phải.
- Chọn lớp là nhóm nút radio 60px; lớp được chọn tô màu cấp tương ứng.
- Bước 3 luôn cho "Bỏ qua, kiểm tra sau".
- Lỗi micro: hướng dẫn bố mẹ bấm Cho phép trên trình duyệt + Thử lại.

4 trạng thái dữ liệu (Bình thường · Đang tải · Trống · Lỗi) và 3 cỡ màn (1440×900 · 1366×768 · 1920×1080, nội dung tối đa 1440px căn giữa) xem ngay trên thẻ xem trước.
