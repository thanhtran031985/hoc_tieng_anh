# Screen07-ListenChoose

Bài "Nghe và chọn hình": đầu bài (thoát, tiến độ, đếm câu), loa lớn, 4 thẻ hình có nhãn phím 1–4, chân bài Nghe lại · Gợi ý · Kiểm tra, và dải phản hồi.

- Phím: 1–4 chọn, Space nghe lại, Enter kiểm tra / tiếp tục.
- Đúng: thẻ xanh + ✓ + sao bay vào thanh tiến độ + dải `ok`.
- Chưa đúng: thẻ cam nhẹ + dải `retry` + rồng động viên; sai 2 lần tự bật gợi ý (làm mờ 2 hình sai).
- Vừa 1366×768: thẻ hình `min(272px, 33cqh)`.

4 trạng thái dữ liệu (Bình thường · Đang tải · Trống · Lỗi) và 3 cỡ màn (1440×900 · 1366×768 · 1920×1080, nội dung tối đa 1440px căn giữa) xem ngay trên thẻ xem trước.
