# Screen11-WordRain

Mini game "Mưa từ vựng": từ (kèm hình) rơi chậm từ trời; bé gõ đúng chính tả rồi Enter để phá.

- Gõ tới đâu, phần chữ khớp được gạch chân xanh tới đó.
- Gõ sai: ô nhập lắc nhẹ, rồng gợi ý từ gần đúng. Từ chạm đất: "sẽ quay lại sau", không trừ điểm.
- Esc hoặc nút ⏸ để tạm dừng.

4 trạng thái dữ liệu (Bình thường · Đang tải · Trống · Lỗi) và 3 cỡ màn (1440×900 · 1366×768 · 1920×1080, nội dung tối đa 1440px căn giữa) xem ngay trên thẻ xem trước.
