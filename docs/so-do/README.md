# Sơ đồ của app

Sơ đồ vẽ bằng archify từ **code thật** (không vẽ từ PRD). Phần chưa làm vẽ nét đứt hoặc màu cam, gắn nhãn "chưa làm · task NN". Mở tệp `.html` bằng trình duyệt (kéo thả vào Chrome hoặc Edge). Giao diện của trình xem (nút Export, Legend…) hiện tiếng Anh vì archify chưa có bản tiếng Việt; nội dung sơ đồ là tiếng Việt.

Chạy lại bằng lệnh `/ve-so-do tong-quan` (hoặc `/ve-so-do NN-slug` cho sơ đồ riêng của một task). Điểm khác giữa code và PRD ghi ở `so-sanh.md` cùng thư mục.
